# Ollama

Ollama is great. It's a software that runs any large language model locally on your machine. And you can set it up with other nifty stuff. It comes bundled with the most popular agents (that's a large language model with a bunch of functions on top) built right in to use.

So I installed Ollama, and I found a good ish model for my environment (a Macbook Pro, 24GB of RAM, M1 processor), qwen3 8b (I first tried qwen latest, but that was hilariously bad, I have never heard my MacBook make a sound, but oh boy did it).

All good, I thought.

The model was about 5 gigabyte of data. Downloaded and ready to go.

Oh boy, Ollama has a plugin in Visual Studio Code, let's go! That's sorted out, I open some of my code, which I don't understand enough about to write fully on my own (hey, I know art and design, shh), which is why I'm experimenting with a local large language model in the first place, and I _ask chat_ like my kids would (not) say. Aaaaand...

Chat is taking forever, and the whole computer is hogged. Nothing. Haha. Oh boy and oh no, and all the ohs. 98% CPU usage, 19GB of ram usage. And the funniest part? The chat didn't come back to me. No answer. It returned a _not enough context size_ error each time. 4 times in a row, after increasing context size each time. So.. I stopped there, and I don't think I'll go back. Maybe in 50 years when this shit works properly.

# What?

Yeah. What? What I learned from this, is..

Running a _LARGE_ language model locally on your own computer, is incredibly resource intensive and you should not do it. Probably. Well maybe, but then you probably have a swarm of computers to do it. Like a, oh I don't know, a data center. Then we're back to square one, and the problem.

This technology (yes, we're still talking about generative artificial intelligence) is bad. Super bad.
